

 React Hooks & State Management Assignment

Project Description:
This project is a React application that demonstrates modern React concepts including Context API, Progressive Web App (PWA), React Hooks, and Redux Toolkit for global state management. The application includes a theme switcher, workout timer, product management system using Redux, and offline support using a service worker.

Technologies Used:
- React.js
- React Router DOM
- Redux Toolkit
- React Redux
- Axios
- Bootstrap
- Service Worker (PWA)

System Requirements:
Before running this project, make sure the following software is installed on your system.

1. Node.js
Download from: https://nodejs.org
Recommended version: Node.js 18 or higher

2. npm (Node Package Manager)
npm is installed automatically with Node.js.
Check installation using:

node -v
npm -v

3. Code Editor (Recommended)
Visual Studio Code
Download from: https://code.visualstudio.com

How to Run the Project:
Follow these steps to run the project on your system.

Step 1: Open Terminal or Command Prompt
Navigate to the project folder.

Step 2: Install Dependencies
Run the following command:

npm install

This will install all required packages listed in package.json.

Main Dependencies Used in This Project:

react
react-dom
react-router-dom
@reduxjs/toolkit
react-redux
axios
bootstrap

Step 3: Start the Development Server
Run the following command:

npm start

The application will start and open automatically in your browser at:

http://localhost:3000

Optional: Run Production Build
To create an optimized production version of the application run:

npm run build

This will generate a build folder containing the production files.

Project Features:

1. Theme Switcher (Context API)
Allows switching between light and dark themes using React Context API.

2. Progressive Web App (PWA)
Includes service worker and manifest file so the application can work offline and be installable.

3. Workout Tracker (React Hooks)
A timer-based workout tracker implemented using useState, useEffect, and useRef with a custom hook.

4. Product Management (Redux Toolkit)
Products are fetched from a mock API and managed globally using Redux Toolkit.
