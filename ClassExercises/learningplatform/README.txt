React Learning Platform (Advanced React Concepts Demo)

Overview This React application demonstrates several advanced React
concepts using a simple learning platform interface with multiple pages.

Features Implemented - Lazy Loading with React.lazy and Suspense -
Performance Optimization using React.memo - Error Handling using Error
Boundaries - Modal rendering using React Portals - Page Navigation using
React Router

Main Pages 
- Courses (Lazy loading demo) 
- Dashboard (React.memo performance demo) 
- Products (Error Boundary demo) 
- Notifications (React Portal modal)

Required Software - Node.js (v16 or higher) - npm

Required Packages - react - react-dom - react-router-dom

Installation Steps
1. Navigate to the project folder: cd learningplatform

2.  Install dependencies: npm install

3.  Start the development server: npm start

Application runs at: http://localhost:3000
