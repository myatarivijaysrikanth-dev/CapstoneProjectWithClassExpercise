How to Run the Project
----------------------

Since node_modules and package.json may not be included in the submission,
install the required dependencies manually using the following steps.

1. Navigate to the project folder

cd bookverse

2. Initialize a new Node project

npm init -y

3. Install required dependencies

npm install react react-dom react-router-dom formik yup flux bootstrap bootstrap-icons --legacy-peer-deps

4. Install React Scripts (required to run the React app)

npm install react-scripts --legacy-peer-deps

5. Start the development server

npm start

6. Open the application in the browser

http://localhost:3000
